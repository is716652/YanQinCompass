# 演禽命盘标准布局（查证与落地口径）

> 缘起：剧本《鉴形》第一案出现"主星井木犴泊乙未宫"，但 app 排盘结果页没有宫位信息，
> 引出问题：禽星命盘有无标准布局？本文为查证结论与落地口径。

## 一、古籍依据（《演禽通纂》卷上起例部分）

《演禽通纂》给出的完整盘面要素：

| 要素 | 起例 | 规则摘要 |
|---|---|---|
| 四柱干支 | 万年历 | 年月日时（引擎已用） |
| **命宫（主宫）** | 起命宫例 | 子上起正月逆数至生月，从该位起子时顺数至生时；干支依五虎遁 |
| **主星** | 起主胎星例 | 旬头星数生日→归子→数至命宫；**泊命宫** |
| **胎宫** | 起主胎宫例 | **年支**起正月顺数至生月→顺数至生日→顺数至生时；五虎遁取干 |
| **胎星** | 同上 | 主星下一位；泊胎宫 |
| 命星 | 起命星例 | 胎星之合宿起子，顺数至命宫 |
| 身宫 / 身星 | 起身宫例/起身星例 | 月×2+日从子逆数；命星合宿起子数至身宫 |
| **寿宫 / 寿星** | 起寿宫例/起寿星例 | 年支对冲，阳男阴女取冲前一位、阴男阳女取冲后一位；命星起子顺数至寿宫为寿星 |
| **大运** | 起大运例 | **就在主星落宫数运**：起运岁数水1火2木3金4土5日6月7；主星落宫天干阳年男顺行/阴年男逆行，女反之；每十年一宫 |
| 小限（行限） | 起行限例 | 安命宫次位顺行，十五/二十五/三十六…… |
| 流年星 | 起流星例 | 胎星作一岁顺数至虚岁 |
| 流月/日/时星 | 起月星/日星/时星例 | 年星起月星、月星管日星（阳角阴室水牛宫诀）、日星加子顺数至生时 |
| 十二宫禽 | 起十二命宫禽 | 财帛/妻妾/奴仆/迁移/官禄/福德/相貌/弟兄/疾厄/田宅/男女等，俱以胎宿为主演至各宫 |

## 二、现代实践旁证

- 徐伟刚（星命观天下，2026）：禽盘软件开发的首要难题即"**主星、主宫、胎星、胎宫**"——
  星宫成对是演禽盘的第一结构；且称市面尚无成熟禽盘排盘软件。
- 通行命例表述（李鸿章盘）：主星翼、胎星轸、命星毕月、身星尾虎——四星为盘面核心，
  论断时皆须言明星落何宫。
- 本 app 项羽案考订（3岁乙未→13丙申→23丁酉→33戊戌）即按"大运自主星落宫起"复原，
  与古籍原注吻合，反证该布局可用。

## 三、本 app 落地口径

1. **星宫绑定**：主星泊命宫（如"主星箕水豹 · 泊癸巳宫"）、胎星泊胎宫——展示层必须成对。
2. **命宫取巳型公式**（与主星例自洽，见 Agent.md"命宫版本矛盾"条）。
3. **大运**：从命宫干支起，起运岁数按主星七曜（水1火2木3金4土5日6月7），
   阳男阴女顺行、阴男阳女逆行，每运十年；展示起运岁+干支，当前虚岁所在运高亮。
4. **寿宫/寿星**：按通纂原文四例验证的规则：阳男阴女取冲前一位，阴男阳女取冲后一位；
   寿星=命星起子顺数至寿宫（命身寿数星不除牛女）。
5. **暂不实现**（依晦涩程度排序，见 Agent.md 待办）：十二宫禽（"克下宿/上宿生胎宿"
   加盘规则需专文考订）、小限、流月/日/时星。

## 四、锚点验证（辛卯年八月初八日子时男）

- 命宫：子上正月逆数至八月=巳；巳起子时=巳 → 命宫巳，五虎遁（辛年）=癸巳 ✓（与古籍主星例同）
- 胎宫：卯起正月顺数至八月=戌；戌起初一数至初八=巳；巳起子时=巳 → 胎宫=癸巳（本例巧合同宫）
- 主星箕水豹（泊命宫癸巳）、胎星斗木獬（泊胎宫）✓ 古籍一致
- 大运：水宿1岁起运，癸阴干+男→逆行：1岁癸巳、11壬辰、21辛卯、31庚寅……
- 寿宫：阴男冲酉取后=申 → 丙申；寿星=命星起子数至申

## 五、结论

禽星命盘**有**标准布局（通纂起例即完整的排盘规范），当前 app 缺的是"星宫绑定 +
大运 + 寿宫寿星"三块，本次补齐；十二宫禽与小限等列为后续。
