## 备注速查

### 明禽 / 暗禽
- **明禽**：昴日鸡（日间得力）
- **暗禽**：尾火虎、箕水豹（夜间得力）

> 口诀：「日值夜则凶，夜值日则贱。」——明禽在夜间失势，暗禽在日间无光。  
> 排盘时需以出生时辰的昼夜判定其力量强弱（详见 `规则/animals_explanation.md` §3）。

### 蛟 vs 龙
- 角木蛟：**无角**水中蛟龙（体型似龙而无鹿角分叉）
- 亢金龙：**有鹿角分叉**的正统长龙

### 猿 vs 猴
- 觜火猴：长尾卷身
- 参水猿：**极长双臂**且**无尾**（长臂猿形态）

### 鹿 vs 獐
- 张月鹿：**有**分枝鹿角
- 柳土獐：**无**角，仅露两颗向下獠牙

## 在 HarmonyOS 项目中引用

将所需 SVG 复制到 `entry/src/main/resources/rawfile/`（与 `animals.json` 同级），在 ArkTS 中通过 `resourceManager.getRawFileContent` 加载，再用 `<Image>` 组件渲染。例如：

```typescript
// utils/BeastImage.ets
const data = await getContext().resourceManager.getRawFileContent(`animals/${name}.svg`);
// 转 dataURL 或 base64 后交给 <Image src={...}>
```

> **注意**：HarmonyOS 的 `<Image>` 默认不直接支持 SVG，需要先将 SVG 解码为位图，或使用支持 SVG 渲染的第三方组件。如仅需在文档/网页中展示 SVG，可放置于项目文档站点中。
